# Data Directory

## Important: Data Confidentiality

**CRITICAL:** All data files containing identifiable participant information must be properly de-identified before being stored in this repository.

## Directory Structure

### `/transcripts`
Store de-identified interview transcripts here.

**File naming convention:** `transcript_P[ID]_[date].txt`
- Example: `transcript_P001_2024-03-15.txt`

**De-identification checklist:**
- [ ] Names removed or replaced with pseudonyms
- [ ] Locations replaced with general regions
- [ ] Specific dates replaced with relative timeframes
- [ ] Healthcare facility names removed
- [ ] Provider names removed
- [ ] Any other identifying information redacted

## Data Security

1. **Never commit identifiable data** to the Git repository
2. Keep original identifiable data in a secure, non-Git location
3. Use the `.gitignore` file to prevent accidental commits of sensitive files
4. Follow all IRB protocols for data handling and storage
