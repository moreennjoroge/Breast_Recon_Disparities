# Breast Reconstruction Disparities Research Project

## Project Overview

This repository contains materials for a qualitative research study examining breast reconstruction decision-making among Black women. The study investigates personal, interpersonal, and systemic factors influencing breast reconstruction choices following breast cancer diagnosis.

## Study Summary

- **Study Type:** Qualitative research study
- **Sample Size:** 11 Black women
- **Median Age:** 45 years (IQR: 10)
- **Data Collection:** Semi-structured interviews
- **Analysis Method:** Thematic content analysis

## Key Findings

Three main themes emerged:
1. **Patient-Provider Communication** - Importance of culturally sensitive interactions and race-concordant visual aids
2. **Financial Barriers** - Concerns about lost income, childcare, and out-of-pocket expenses
3. **Medical Mistrust** - Rooted in historical racial disparities in healthcare

## Data Management

### Interview Data
- All interview transcripts should be stored in `data/transcripts/`
- Ensure all data is de-identified before committing to the repository
- Follow IRB protocols for data storage and sharing

### Analysis Files
- Qualitative coding files and thematic analysis materials go in `analysis/`
- Include coding schema, theme development documents, and analysis memos

## Figures and Tables

- Store all figures in `figures/` directory
- Create tables in the manuscript or as separate files in `figures/`
- Use descriptive file names (e.g., `fig1_participant_demographics.png`)

## References

- Store bibliography files (BibTeX, EndNote, etc.) in `references/` directory
- Consider using a reference manager for consistency

## Supplementary Materials

- Additional materials for journal submission go in `supplementary/`
- This may include extended data tables, additional quotes, or supplementary methods

## Getting Started

1. Review and edit the main manuscript at `manuscript/main_manuscript.md`
2. Add de-identified interview data to `data/transcripts/`
3. Document your analysis process in `analysis/`
4. Create figures and tables in the `figures/` directory
5. Maintain research notes and todos in `notes/`
